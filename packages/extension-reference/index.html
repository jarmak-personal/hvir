hvir extension contract 1.0

Bring a useful view into your workbench

This ordinary directory package runs in an isolated view. It can request its own declared detail tab and read presentation values. It has no project-file, terminal, network, or executable access.

Try the lifecycle

Close either tab through hvir's controls. Disable the extension in Settings to close all its views. Changes in the source directory do not change the accepted code already running.

You can switch workspaces while this application-level tab stays available. The view gains no access to the selected project.
